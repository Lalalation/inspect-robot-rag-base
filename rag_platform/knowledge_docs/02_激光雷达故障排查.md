# 激光雷达故障排查手册
## 故障1：雷达无数据，rqt查看topic无点云
现象：启动后雷达不输出点云，导航无法启动
排查步骤：
1. 检查雷达供电线缆、网口是否松动
2. 查看雷达IP是否和工控机在同一网段
3. 重启雷达电源，重启ros雷达驱动节点
4. 以上无效，判定雷达硬件故障，需要更换雷达
## 故障2：雷达点云噪声大、定位漂移
现象：机器人定位抖动、容易跑偏
排查步骤：
1. 清理雷达镜头灰尘、水雾
2. 检查周围是否有透明玻璃、强反光物体（容易干扰激光）
3. 重新执行SLAM地图校准
## 故障3：雷达报超时断开
现象：雷达间歇性掉线，导航任务中断
原因：网线接触不良、带宽不足
处理：更换屏蔽网线，减少交换机端口占用
